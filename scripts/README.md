# Scripts

This directory contains helper scripts for building, packaging, and diagnosing the GammaRay project.

## `list_gammaray_render.ps1` / `list_gammaray_render.bat`

List all running `GammaRayRender.exe` processes with their full command-line arguments.

### PowerShell

```powershell
# Default: list GammaRayRender.exe
.\list_gammaray_render.ps1

# List a different process
.\list_gammaray_render.ps1 -Name "GammaRay.exe"
.\list_gammaray_render.ps1 -Name "GammaRayClientInner.exe"
```

### Batch (double-click)

Run `list_gammaray_render.bat` directly. It defaults to `GammaRayRender.exe` and keeps the window open with `pause`.

## Server packaging scripts

These scripts build a Rust server + its Vue frontend and collect everything
into `output\<server>\` for standalone deployment.

### `ensure_tls_cert.bat` (shared helper)

Called by all three `package_gr_*` scripts. Generates a 100-year self-signed
TLS certificate **once** at `<repo>\certs\` and copies it to each server's
`certs\` output directory. Also locates or auto-downloads OpenSSL. The
certificate is reused across all servers, so it is only generated on the
first run of any packaging script.

### `package_gr_auth_server.bat`

Packages `px_auth_server` (the license/auth server).

```text
output\px_auth_server\
├── px_auth_server.exe
├── gr_auth_server_settings.toml
├── certs\          # cert.pem, key.pem, auth_license_public.key, auth_license_private.key
└── web_auth\       # built frontend assets
```

Run `output\px_auth_server\px_auth_server.exe` and open `https://localhost:30400`.

### `package_gr_cms_server.bat`

Packages `px_cms_server` (the CMS/management server). Depends on MongoDB and
Redis. Reuses the Ed25519 license public key generated by
`package_gr_auth_server.bat` (copy it from `output\px_auth_server\certs\`
or set the `GR_AUTH_LICENSE_PUBLIC_KEY` env var).

```text
output\px_cms_server\
├── px_cms_server.exe
├── gr_cms_server_settings.toml
├── certs\          # cert.pem, key.pem, auth_license_public.key
├── web\            # built frontend assets
└── uploads\        # runtime: logs, avatar, update_info
```

The CMS pulls its authorization from the auth server at runtime
(`auth_server_url` in `gr_cms_server_settings.toml`, see
`docs/gr_cms_auth_pull.md`); no local license file is shipped.

Run `output\px_cms_server\px_cms_server.exe --running-mode=server` and open
`https://localhost:30500` (health check: `http://localhost:30499/ping`).

### `package_gr_desk_server.bat`

Packages `px_desk_server` (the desk/official server). Depends on MongoDB.

```text
output\px_desk_server\
├── px_desk_server.exe
├── certs\          # cert.pem, key.pem
└── static\         # built frontend assets
```

Run `output\px_desk_server\px_desk_server.exe` and open
`http://localhost:5000` or `https://localhost:5001`.
