# PostgreSQL 设备目录与授权契约

> 2026-09-17，Console DB2-B repository 增量。实现入口 `px_console_store::DeviceStore`。
> 不代表设备登记 HTTP/WS、节点在线、真实桌面连接或全部 Console 已切换。实际验收见[实施状态](server_database_execution_status.md)。

## 身份与配置

设备数据库身份为 UUID，公开查找编号 `public_code` 是独立生成的 12 位数字字符串，唯一且不可修改。
公开编号不是口令、不由机器硬件散列推导，也不能作为 owner、node 或 CloudApplication target。
数据库 UUID、公开编号、设备登记凭据、节点控制身份彼此分开；不解析旧开发版编号或恢复旧 seed/MD5 逻辑。
编号冲突由唯一约束拒绝，创建事务无任何残留，调用方不能把冲突解释成已登记的同一机器。

当前登记由管理员授权创建；业务层生成 CSPRNG 高熵凭据，只把 32 字节 SHA-256 摘要交给 repository。
`DeviceProfile` 只含 id、公开编号、显示名称、平台、disabled、revision、registered_at，不含摘要、密码或凭据。
设备凭据只验证设备身份，不能用于管理员登录或节点命令；成功验证不是在线证明，也不分配默认 endpoint。
本增量没有直接公开的匿名登记、密码连接/分享链接接口，后续统一入口需独立授权/限流，不得把编号变成凭据。

名称 1–128 个 Unicode 标量，无控制字符/首尾空白；平台为 windows/linux/macos/android 明确枚举。
数据库约束同时约束平台、编号长度、hash 长度、正 revision 与外键。平台在登记时确定，不通过普通改名接口改写。
配置、关联替换、凭据轮换、删除都要求当前 revision。未知/已删除设备拒绝，不根据旧端口认领另一个设备。

## 权限与事务

管理入口要求 AdminWeb 登录会话 + 当前 admin 角色；viewer 仅管理去密读取。Panel/Android 会话不能调用管理写入。
资源读取要求 panel/android/user_web 中与会话精确相同的 client_type，且当前 role 为 user/admin；viewer 不可代用户连接。
用户只能看到自身 `user_devices` 关联或活跃组 `group_device_grants` 授予的、未停用/删除设备。
目录和单设备读取使用同一 SQL 策略。管理员身份不自动获得所有设备的用户访问权。

关联用户与授权组一次完整替换，每类最多 1000 个 UUID；拒绝重复、未知、停用/删除的新用户或已删除组。
更改遵循[身份契约](postgresql_identity_contract.md)的事务 gate：独占 gate → 管理主体 → 设备 → 组/用户 → 更新。
比较前后有效用户集合：实际变化用户的授权 revision、撤销 outbox 与设备审计必须同事务提交。
仅改变同一有效权限的表示方式不会使该用户退出；完全相同集合且 revision 正确时无版本或审计副作用。
用户组成员变更/删除组由 GroupStore 的同一 gate 和撤销事务覆盖；已软删除组的历史 grant 不再授权。

停用/重新启用、凭据轮换和软删除会撤销相关用户已有登录授权版本，防止旧 token 随恢复状态再次有效。
轮换后旧设备凭据立即不能再次认证；节点长连接的实时断开/代际切换属于尚待接通的节点层，不冒充已完成。
改名不改变权限，不迫使用户退出。所有实际修改追加一条无秘密的 device_audit，设备与 revision 唯一。
删除仅设置终态时间、增加 revision、发撤销事件，保留关联与审计，不清理任何 Windows 账号/Profile/Session/进程。

读取持有共享 gate 到事务结束。返回的 DeviceProfile 不是可复用授权票据；后续启动/descriptor 必须在其副作用事务内
再次调用同一策略并持有 gate 到提交，禁止“先读可见、释放锁、稍后无检查启动”。当前未交付该连接启动业务。

## 验证

`tests/devices.rs` 的 8 项真实 PG 用例：

1. UUID/公开编号/凭据不可混用，重复凭据、非法名称拒绝，DTO 与列无旧密码材料。
2. 管理角色/终端类型/资源访问分开判断，拒绝操作不写事件或审计。
3. 直接关联与组授权同策略，Android 不冒充 Panel，仅实际受影响用户撤销。
4. 无效关联和撤销 outbox 插入失败时，先前删除/插入、revision、审计全部回滚；去除故障后可成功。
5. 20 路 CAS 更新一个胜者、一条审计，旧 revision 不可删除胜者。
6. 停用、恢复、轮换、软删除都不复活旧用户 token，旧设备 key 轮换后永久失效，关联和审计保留。
7. 删除组后新旧会话均不能再取得该组设备，历史 grant 不构成权限。
8. UUID 稳定游标分页、条数限制、到期即拒绝、关闭数据库连接池后不返回成功。

运行器在 Windows/Linux 执行，SQLx 在线编译/离线元数据一致性、三库数据/索引/约束恢复包含新四表。
当前未完成：登记/连接 HTTP/WS、节点凭据代际、公开编号查找入口及其限流、实际撤销投递、桌面密码/分享访问、客户端接入。
