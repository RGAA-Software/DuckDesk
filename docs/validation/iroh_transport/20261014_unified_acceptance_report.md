### 负载、分布与时间范围

业务场景为本批自有、无需外站加载的动态WebView页面，视频上限配置2000kbps。源日志显示低运动画面实际视频码率约0.034–0.074Mbps，四小时均值0.05414Mbps。配置上限不代表实际持续发送2Mbps，因此本轮证明持续业务可用和退出行为，不能用于宣称2Mbps持续负载、带宽上限或满容量通过。

T5两条业务实际为LAN直连及Windows Relay，BJ并未分到该批业务。Windows Relay端点数5→关闭第一路后3→清理后1，BJ为0；端点数与业务流路数不是同一计数。T3c已单独取得BJ真实业务证据，不把T5目录名中的“bj”或期望分配当实际路径，不声称均匀分布或十台Relay验收。

四小时从北京时间02:03:59至06:03:59；Client于06:04:46确认正常退出，原命令succeeded/exit0。全部轮转候选日志按完整区间筛选，双端原始日志约26.53MB/16.42MB，远端压缩后下载约2.16MB/1.07MB，SHA分别为`86B35818F154FF08E7E15F7F9009EDA2A4CF1BE480819C06927977530436B2D4`、`B4E823F2C957B3A72B16165AB1F89C3AB11AB30654BA7FEEB68506A623CC983C`。没有拼接不同进程/版本/分段来凑四小时。

## 本批失败记录与处理

- 原T3a监督任务interrupted，样本媒体数据有效但正常退出未知。监督v2/v3在采样后保持父进程，等待真实正常关闭；T5a补验成功，原任务未改写成exit0。
- 首次T3b旧用户context被拒，尚未创建远端进程；该资源已回收，不计有效媒体样本。刷新当前context后T3b-r1通过。
- 原探针期限不足及无Relay仍等待上线的问题，只修改验收探针；持续期限扩至600秒，无候选直连对照可执行。独立WFP附件Release/18jobs、格式和严格Clippy通过，探针focused Release/18jobs及格式通过，产品没有重编译。
- 活动JSON报告读共享句柄失败，改共享读取；首次无界日志尾读超时，改有界64KiB读取。四次Source PAB下载offset0超时保留原操作ID；3.7KB压缩证据经原生读回并SHA核对，后续重新建立管理连接的压缩下载正常。没有将工具错误定因为视频UDP或网卡故障。
- 无Relay探针在全部消息校验通过/退出0后出现上游`relay_recv_channel closed`退出诊断，原日志保留，未改第三方实现。一次错误Windows服务名称只读查询已改用实际服务名，没有执行停服动作。

本次功能缺陷没有未闭环项；画面短抖动、ViGEm和上游退出诊断作为明确限制保留。
