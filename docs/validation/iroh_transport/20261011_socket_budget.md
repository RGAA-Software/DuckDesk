## 实现与交付

- `VideoSendPacing` 在连续视频帧之间共享发送额度，每批最多 4 片；计入 FEC 后的分片及每片 128 字节保守协议余量，视频提交预算 9.6Mbps。
- iroh 视频编码上限 6.5Mbps，为 FEC、协议和音频预留空间。保留现有自适应降码率和 QUIC 拥塞控制；文件、RDP 可靠流及旧 Native 路径未施加该视频预算。
- 定时等待让出执行器，延迟恢复最多补一个批次；不积累长时间闲置额度。该限制作用于应用向 QUIC 提交，不能保证 QUIC 排队后的真实网卡瞬时线速也严格为 9.6Mbps。
