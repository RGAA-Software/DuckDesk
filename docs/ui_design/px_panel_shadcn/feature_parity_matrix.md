# px_panel / px_client 功能守恒清单

本清单以 2026-09-13 当前 `src/px_panel/ui_imgui` 源码为依据。设计调整可以改变位置、密度、组件外观和信息层级，但不得改变这里列出的能力。

## 全局框架

- 账户头像和名称；未登录时头像入口打开登录/注册 Dialog。
- 远程控制、设备列表、云应用、服务状态、安全、设置六个入口。
- 退出程序。
- 简体中文、English、深色、浅色。
- 最小化、关闭；不提供最大化按钮，外层窗口轮廓由系统处理。
- Dialog、Toast/通知与语音呼叫同意浮层继续存在，不修改业务条件。

## 远程控制

- 本机设备 ID：展示、复制。
- 本机设备名称：展示、编辑、保存、取消和失败反馈。
- 临时密码：展示/隐藏、复制。
- 桌面连接链接：展示、复制完整值。
- 网页客户端地址：展示、复制完整值、打开完整值。
- 管理服务在线/离线状态。
- 刷新远程设备。
- 输入设备 ID、`link://`、IPv4/主机和可选端口并连接。
- 最近设备最多六个、三列两行、按最近使用时间排序。
- 设备卡展示在线状态、9 位码或 IP、设备名。
- 双击开始控制；右键开始控制、仅观看、编辑设备、文件传输、删除。
- 需要时显示连接密码 Dialog。
- 编辑设备保留：设备名、采集音频、剪贴板、仅观看、分离窗口、强制软件解码、强制 TCP、强制 Relay、等待调试器、强制 GDI 捕获、禁用 Vulkan、保存、取消。
- 删除设备确认。

## 设备列表

- 按设备名或设备 ID 搜索；刷新。
- 列表展示在线状态、设备名、9 位码或 IP。
- 选择设备后展示名称、ID、主机、端口、状态。
- 双击开始控制。
- 开始控制、仅观看、文件传输、复制 ID、编辑设备、删除设备。
- 与远控首页最近设备共享同一数据源，删除/编辑同步。

## 云应用

- 刷新应用列表。
- 三列卡片；应用名称、运行/停止状态。
- 双击启动应用。
- 右键菜单：启动应用、仅观看、停止应用、强制 TCP、强制 Relay。
- 应用需要时显示密码 Dialog，保留连接和取消。
- 业务繁忙时禁用不允许的动作；错误继续使用标准通知。

## 服务状态

- 控制器驱动：正常/不可用；不可用时提供安装。
- 渲染服务：正常/不可用；始终提供重启。
- 节点服务：正常/不可用。
- 已连接客户端数量。
- 一个或多个网络地址及有线/无线类型。
- Panel 监听端口、桌面连接端口。

## 安全记录

- 访问记录、文件传输记录两个 Tabs。
- 访问记录：连接类型、开始、结束、访问设备、目标设备、持续时间、操作。
- 文件传输记录：结果、开始、结束、访问设备、目标设备、方向、文件名、操作。
- 每条记录：复制、复制 JSON、删除。
- 清空全部。
- 删除/清空要求长期密码；密码错误提示；取消。
- 无记录空状态。

## 设置 / 常规

- 码率，校验无效码率。
- 帧率：15、30、60、90、120、144，校验无效帧率。
- 视频编码：H.264、H.265（HEVC）。
- 调整分辨率；宽度、高度；关闭时禁用关联输入。
- 校验无效/不支持分辨率和宽高比。
- 采集音频。
- 保存；保存成功后询问立即重启 Render 或稍后。
- 高级视觉效果开关是此前已经确认的本轮 UI 基础能力，不扩展其他产品功能。

## 设置 / 网络

- 授权信息，多行编辑；编辑完成触发解析。
- 解析后的控制端点：Supervisor 端口/节点管理用途、Relay 端口/可靠路由连接用途。
- 节点公网地址和可选提示。
- 节点监听端口：服务管理端口、桌面连接端口、应用端口池、RTC 媒体端口池、Panel 监听端口及各自用途。
- 保存、验证、当前状态反馈；需要时显示立即重启/稍后。

## 设置 / 安全

- 断开连接自动锁定。
- 长期密码、确认密码、设置密码。
- 输入不合法、正在更新、已更新、远端更新失败状态。
- 维护工具：清除数据及确认 Dialog。
- 日志保存位置、收集日志。
- 正在收集、完成、失败状态。

## 设置 / 控制器

- 最大化 Client、显示 Client Logo、彩色标题栏。
- 最大屏幕数量：2、4、6、8。
- 首选解码器：自动、硬件解码、软件解码。
- 录像路径、保存。

## 设置 / 关于

- Pixels 名称、版本、产品说明。
- 检查更新、GitHub、网站。

## px_client 悬浮控制器

- 悬浮球保持前景显示；单击展开/关闭，拖动后限制在当前 viewport 可见范围。
- 点击悬浮球以外画面不会移动悬浮球；点击菜单外关闭菜单，关闭动作不发送到远端。
- 一级菜单显示连接状态、FPS 和延迟；显示、控制、工具、语音、设置按层级展开二级菜单。
- 显示器、分辨率、帧率、声音、全屏、虚拟屏增减。
- 安全注意键；远端鼠标、键盘、滚轮、文本和剪贴板输入路由保持现有实现。
- 文件传输、截图、开始/停止录制、连接统计。
- 语音呼叫/挂断、麦克风静音、扬声器静音。
- 简体中文/English、深色/浅色、普通/高级视觉效果。

## px_client 文件传输与反馈

- 远端路径打开、本地路径、上传、下载选择。
- 远端文件名称/类型/大小，目录双击进入。
- 传输任务方向、进度、速度、取消和错误。
- 目标覆盖、应用到全部、跳过。
- 启动请求无效、窗口/图形设备创建失败、会话创建失败和等待调试器提示。
- 鉴权拒绝、设备占用/5 秒宽限、策略拒绝、被接管和传输拒绝的分类错误。
- 媒体暂不可用与断开重试使用页内告警，不改变会话重试逻辑。
