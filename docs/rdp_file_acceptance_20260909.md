## 通过项

- **双向文件/目录、中文和空格路径、空文件**：远端传出目录包含 `中文 目录\sample file.txt` 和空文件；
  本机上传目录包含 `中文 file.txt` 和空文件。非空文件双向 SHA-256 与源内容相同，空文件长度为 0。
  本轮随机测试内容 SHA-256：`3CC91CE9CD4F0733BE01F52B92DB4CD31E91716D21FEB75DF98F8B3E842098BD`。
- **同名目录合并冲突取消**：先成功上传，再仅在测试副本写入不同 sentinel 内容；再次粘贴，
  截图确认 Windows Explorer 出现“确认文件夹替换 / 合并”对话框，发送 Escape 后原内容不变。
  这验证目录冲突取消，不等于已经点击同意合并后的逐文件替换/跳过策略全部通过。
- **真正接收中途取消**：远端独立 32 MiB 文件，观察到本机专属 staging 中已有 65,536 字节、尚未完成，
  再用新的本地文本替换剪贴板。staging 目录消失，等待后新文本仍保留，没有旧文件重新发布覆盖。
  此为“替换剪贴板触发取消”，不是点击独立传输管理器的取消按钮。
- **补充单测**：`client_rdp_clipboard_channel`、`client_rdp_clipboard` 两个 CTest 均通过，0.98 秒。
  包括取消时释放远端快照锁、忽略迟到响应、临时文件 RAII 清理，以及路径/重解析点/硬链接拒绝等已有断言。
